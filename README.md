# P 人旅行助手 Demo

一个面向 MBTI P 型用户的弹性旅行规划产品概念 Demo。

## 核心产品理念

P 型用户并不是完全不需要计划，而是不希望被过度细致的计划束缚。
这个 Demo 强调：

- 只决定“下一站”，而不是排满全天行程
- 根据当前心情、预算和剩余时间推荐选择
- 行程可以随时取消、插入和重排
- “改变计划”本身就是正常旅行体验的一部分

## 本地预览

直接双击 `index.html` 即可打开。

## 使用 GitHub Pages 发布

1. 在 GitHub 新建一个公开仓库，例如 `p-travel-demo`
2. 将本项目中的全部文件上传到仓库根目录
3. 打开仓库 `Settings`
4. 进入 `Pages`
5. 在 `Build and deployment` 中选择 `Deploy from a branch`
6. Branch 选择 `main`，目录选择 `/ (root)`
7. 保存

稍等片刻后，可通过：

`https://<你的GitHub用户名>.github.io/p-travel-demo/`

访问。
