# P 人旅行助手 Demo

一个面向 MBTI P 型用户的弹性旅行规划产品概念 Demo。

## 核心产品理念

P 型用户并不是完全不需要计划，而是不希望被过度细致的计划束缚。
这个 Demo 强调：

- 只决定“下一站”，而不是排满全天行程
- 根据当前心情、预算和剩余时间推荐选择
- 行程可以随时取消、插入和重排
- “改变计划”本身就是正常旅行体验的一部分
